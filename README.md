# Обустройство квартиры — прототип

Конструктор комнаты для Telegram Mini App. Статический сайт: сборки нет, сервера нет, всё работает в браузере.

Живая версия: подставится после включения GitHub Pages.

## Как включить мини-апп в боте

1. Открыть [@BotFather](https://t.me/BotFather) → `/mybots` → выбрать бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Прислать адрес сайта (тот, что выдал GitHub Pages) и подпись кнопки, например «Обустроить комнату».

После этого кнопка появится в меню бота рядом со скрепкой.

Если нужна не кнопка меню, а обычная кнопка в сообщении — в коде бота отправляется клавиатура с `web_app`:

```python
from telegram import InlineKeyboardButton, InlineKeyboardMarkup, WebAppInfo

kb = InlineKeyboardMarkup([[
    InlineKeyboardButton("Обустроить комнату", web_app=WebAppInfo(url=PAGES_URL))
]])
await update.message.reply_text("Поехали", reply_markup=kb)
```

Адрес должен быть на `https://` — GitHub Pages это даёт сам.

## Как обновлять

Любой коммит в `main` → Pages пересобирается сам, минута-две. Ничего запускать не надо.

Файл правится прямо на сайте GitHub: открыть файл → карандаш → **Commit changes**.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | разметка, вся вёрстка и стили |
| `app.js` | 3D-сцена, каталог товаров, шаги, конвертер «фото → предмет» |
| `tg.js` | прослойка для Телеграма: высота окна, блокировка свайпа вниз |
| `lib/` | three.js и его модули |
| `fonts/` | Geist и Oswald, порезанные под нужные начертания |

## Что нужно знать про данные

Комната живёт в памяти вкладки и **не сохраняется**: закрыл мини-апп — собирать заново. Свои вещи из фото лежат в `localStorage` браузера (до 40 штук) — на другом телефоне их не будет.

Пароли, токены и ключи в репозитории не лежат и лежать не должны: токен бота хранится только в BotFather и в окружении самого бота.

Мини-апп ничего не отправляет наружу. Фотографии, которые пользователь загружает, остаются на его телефоне.
